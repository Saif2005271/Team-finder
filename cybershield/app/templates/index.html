How k-Anonymity Works (Password Mode)

Your password is hashed locally using SHA-1. Only the first 5 hex characters of that hash are sent to the HaveIBeenPwned API. The API returns all breach hashes matching that prefix (~500 results). Your browser checks if the full hash matches locally. Your actual password is never transmitted. This is the k-anonymity model developed by Troy Hunt.

Email Mode — API Key Required

Email breach lookups require a HaveIBeenPwned API key (paid, ~$3.50/month). Add HIBP_API_KEY=your_key to your .env file. Without a key, the tool shows a sample response.

What is Stalkerware?

Stalkerware (also called spouseware or creepware) is software secretly installed on a device — usually by a partner, family member, or employer — to covertly monitor calls, messages, location, and media. It requires brief physical access to install and hides itself from app lists and notification trays. The Coalition Against Stalkerware estimates millions of devices are affected globally.

WebRTC IP Leak Test
Detect if WebRTC is bypassing your VPN and exposing your real IP
How This Test Works

WebRTC (Web Real-Time Communication) allows browsers to establish direct peer connections for audio, video, and data sharing. To find the optimal route, it uses the ICE protocol to discover all available network interfaces — including your real public IP — using STUN servers. This test creates a dummy WebRTC peer connection to collect all discovered IPs, then compares them against what the server sees. A mismatch when you're using a VPN indicates a leak.

DNS Leak Test
Identify which DNS servers are resolving your queries
Why DNS Privacy Matters

DNS (Domain Name System) translates domain names to IP addresses. By default, your ISP assigns your DNS resolver, giving them visibility into every domain you visit — even when using HTTPS. DNS-over-HTTPS (DoH) encrypts queries to prevent this interception.

A DNS leak occurs when your device bypasses your configured secure DNS (e.g., a VPN's internal resolver) and falls back to your ISP's resolver. This test probes multiple DoH endpoints to identify which resolver is actually handling your requests.
